# Accessibility Standard (A11Y)

| | |
|---|---|
| Version | 1.0 |
| Owner | Accessibility Office |
| Baseline | WCAG 2.1 Level AA |

| ID | Rule | Enforcement |
|---|---|---|
| A11Y-01 | Every page declares its language (`<html lang="en">`). | Automated - FAIL |
| A11Y-02 | Every image has an `alt` attribute; decorative images use `alt=""`. | Automated - WARN |
| A11Y-03 | All functions work with a keyboard; focus is visible; a skip link is provided. | Manual review |
| A11Y-04 | Text contrast is at least 4.5:1 (3:1 for large text). | Manual review |
| A11Y-05 | Form fields have labels; status messages are announced to screen readers. | Manual review |
